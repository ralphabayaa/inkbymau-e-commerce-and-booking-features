## Introduction

InkbyMau is a website for an illustrator and henna artist. It brings together an artwork portfolio, a product shop, booking requests, and a customer space for communicating with the artist.

This repository showcases the project's design, features, and development approach. The application source code is private.

## Features

- Artwork portfolio featuring illustrations and henna designs.
- Recent events section.
- Product shop with a shopping bag and checkout flow.
- Booking requests for henna sessions, events, and custom illustrations.
- **Studio Space:** a customer portal for bookings, orders, and messages.
- Design reference uploads and payment proof submission.
- GCash payment instructions with manual verification.
- Admin tools for managing studio activity.
- Responsive layouts for desktop and mobile screens.

## The Process

The project connects three parts of the studio experience: discovering the artist's work, requesting a service or purchasing a product, and following up through a customer account.

The interface reflects the artist's visual identity while giving visitors clear paths to browse, shop, book, and get in touch.

## How I Built It

The frontend uses HTML, CSS, and JavaScript, with separate pages for the public website, customer portal, and admin dashboard.

Supabase connects the interface to authentication, stored records, uploaded files, and realtime communication. Database migrations define the data structure and access policies, while TypeScript Edge Functions handle server-side integrations.
